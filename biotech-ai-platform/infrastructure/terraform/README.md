# Terraform Infrastructure as Code

This directory contains Terraform configurations for provisioning and managing the cloud infrastructure required by the BioTech AI Platform (e.g., on AWS, GCP, Azure).

Subdirectories might include:
- `modules/`: Reusable Terraform modules (e.g., for VPC, Kubernetes cluster, databases).
- `environments/`: Environment-specific configurations (e.g., `dev`, `staging`, `prod`).
