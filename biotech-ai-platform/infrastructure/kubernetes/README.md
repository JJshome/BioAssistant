# Kubernetes Manifests

This directory contains Kubernetes manifest files (YAML) for deploying the BioTech AI Platform to a Kubernetes cluster.

Subdirectories might include:
- `charts/`: Helm charts for different components or the entire platform.
- `services/`: Manifests for individual services (Deployments, Services, ConfigMaps, etc.).
- `volumes/`: PersistentVolumeClaim definitions.
- `ingress/`: Ingress controller configurations.
